# 🌐 Parkhi's Portfolio Website

Welcome to my personal portfolio website!  
Built using **HTML**, **CSS**, and **JavaScript**, this site showcases my skills, projects, certifications, and contact information. Designed with a clean, responsive layout and a focus on UI/UX.

---

## ✨ Features

- 🎯 Clean, responsive design for all screen sizes
- 📁 Sections: About Me, Projects, Certifications, Experience, Contact
- 📄 Resume download functionality
- 📬 Contact form integrated with FormSubmit for email submissions
- 🌐 Linked social media icons (GitHub & LinkedIn)

---

## 🧠 Tech Stack

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**
- **FormSubmit** (for contact form backend)
- **Hosted on Netlify**
